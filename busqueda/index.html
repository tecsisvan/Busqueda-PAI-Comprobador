Cómo se usa

  1. Descarga y abre Busqueda.exe. Windows puede mostrar un aviso de SmartScreen la primera vez: Más información → Ejecutar de todas formas.
  2. Elige el módulo y pulsa 🌐 Iniciar Chrome (sesión). Se abre un Chrome con un perfil propio de la herramienta.
  3. En esa ventana inicia sesión en el portal (PAI o ADRES). La sesión queda guardada en ese perfil, así que este paso sólo se repite cuando expire.
  4. Selecciona el archivo CSV de códigos. Debe tener las columnas consecutivo y codigo.
  5. Escoge una consulta predeterminada o marca P. Personalizada y elige campo por campo.
  6. Pulsa ▶ Iniciar consulta. El archivo de salida se guarda junto al ejecutable y se va actualizando registro a registro.
